# Task 07: Git Version Control & GitHub Repository Setup

## 🎯 Task Objective
Initialize Git repository tracking, establish clean commit history, configure remote origin, authenticate using GitHub Personal Access Tokens (PAT), and enable GitHub Pages live web deployment.

---

## 💻 Executed Git Commands & Process

```bash
# 1. Initialize local repository
git init
git branch -M main

# 2. Stage all core files and commit
git add .
git commit -m "Initial commit: Oops! game"

# 3. Authenticate and push to remote repository
git remote add origin https://github.com/khalidabdullahh/Oops.git
git push -u origin main
```
