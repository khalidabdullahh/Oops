# 📬 Player Feedback & Community Bug Reports

Welcome to the **Oops! Community Feedback & Report Center**!

This directory documents player feedback, level balance suggestions, and bug reports submitted through the in-game **💬 Feedback** button or filed directly on GitHub Issues.

---

## 🌐 How Feedback is Submitted:

1. **In-Game Submission**:
   - Players can click the **💬 Feedback** button at the top-right of the game (available in both desktop and mobile modes).
   - The game captures context (current World, Level, Death count, resolution, and player thoughts).
   - Clicking **"Submit to GitHub"** directly creates a formatted issue on GitHub at **[Oops! GitHub Issues](https://github.com/khalidabdullahh/Oops/issues)**.

2. **Direct GitHub Issues**:
   - Anyone can file a new feedback ticket directly using the [User Feedback Template](https://github.com/khalidabdullahh/Oops/issues/new?template=user_feedback.md).

## 🤖 How Reports Are Processed:
- **Bug Reports**: Investigated immediately with automated headless Chrome simulation tests.
- **Difficulty & Balance Suggestions**: Analyzed across jump metrics, platform gaps, and hazard timings.
- **New Gimmicks & Level Ideas**: Incorporated into upcoming Multiverse worlds and expansion packs.
