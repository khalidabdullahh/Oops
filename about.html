About Oops!

Oops! is a comedy-driven, deceptive multiverse platformer game where traditional gaming intuition is your biggest trap! Inspired by legendary rage-puzzle titles like Level Devil and Cat Mario, Oops! challenges players with unexpected mechanical surprises, shifting terrain, and hilarious fakeouts.

🎮 Game Features

🏜️ 30 Handcrafted Levels

Zero repetition. Every stage introduces fresh puzzles, falling bridges, flee-gates, and spring traps.

📱 Instant Dual-Orientation

Built for both desktop keyboards and mobile touchscreen gamepads in portrait and landscape modes.

⚡ Sub-Second Load Times

Ultra-lightweight HTML5 & Phaser 3 architecture running at smooth 60 FPS on any modern browser.

🛠️ Technology & Open Standards

Oops! is built using open web standards:

  • Game Engine: Phaser 3 (HTML5 Canvas & WebGL)
  • Audio: Native Web Audio API procedural sound synthesizer (zero external audio file latency)
  • Packaging: Progressive Web App (PWA) & Capacitor Mobile ready
  • Hosting & Edge Delivery: Cloudflare Edge CDN & Vercel Worldwide Edge Network
