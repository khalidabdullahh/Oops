## 🌟 Features

- **Deceptive Level Design:** Invisible traps, fake platforms, trolling spikes, dynamic hazards, and sudden surprises.
- **Synthesized Web Audio SFX:** Pure Web Audio API retro sound effects with no external audio files required.
- **Responsive Canvas:** Automatically scales to fit any screen resolution while maintaining pixel-sharp rendering.
- **Multiple Challenge Levels:** 10 increasing difficulty levels with death counters, level timers, and star ratings.
- **Zero Dependencies:** Built entirely with vanilla JavaScript, HTML5 Canvas, and modern CSS.

| Action | Keys |
|---|---|
| **Move Left / Right** | `←` / `→` or `A` / `D` |
| **Jump** | `↑` / `W` / `Space` |
| **Quick Restart** | `R` |

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python 3
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.
